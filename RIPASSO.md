# file di ripasso di git 

## Elenco di procedimenti per fare una repository e spedirlo su repository remoto

* passo creazione e inizializzazione della repository
* aggiungiamo un file md per inserire delle informazioni
* andiamo ad aggiungere il file tra i file "tracciati"
* di seguito andiamo a fare il commit
* Modifichiamo il nome del ramo
* andiamo a fare il collegamento della repository ( tra quello locale sul pc e quello su remoto come git hub )
* facciamo il push della repository

- questo file è di utilizzo per il ripasso dei comandi di git e di inserimento di informazioni ( dopo aver fatto i commit e con aggiunte e unione di ramificazioni )
